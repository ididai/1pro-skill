# 1pro-skill

`1pro-skill`은 모호한 요청을 실행 가능한 고품질 질문과 작업 명세로 정제하는 Codex 스킬입니다.

Current version: `1.1.0`

대충 던진 아이디어, 애매한 프롬프트, 불완전한 기능 요청을 Codex나 개발자가 바로 이해할 수 있는 형태로 바꿔줍니다.

## When To Use

- 요구사항이 두루뭉술해서 바로 작업하기 어려울 때
- 프롬프트를 더 날카롭고 실무적으로 바꾸고 싶을 때
- 누락된 결정사항, 제약조건, 성공 기준을 먼저 드러내고 싶을 때
- 기능 요청을 개발자가 바로 작업할 수 있는 명세로 바꾸고 싶을 때
- 초보자도 이해할 수 있게 쉬운 설명과 추천 기본값이 필요할 때

## What Changed In 1.1

- 기존 질문 정제 흐름은 유지했습니다.
- 실행 작업을 위한 `작업 명세` 섹션을 추가했습니다.
- `범위`, `비범위`, `성공 기준`, `검증 방법`을 더 명확히 다루도록 개선했습니다.
- 모호한 표현을 측정 가능한 기준으로 바꾸는 규칙을 추가했습니다.
- 초보자 설명은 더 짧고 안전한 기본값 중심으로 정리했습니다.

## Repository Contents

- `SKILL.md`: 스킬 본문
- `agents/openai.yaml`: OpenAI 계열 호출 메타데이터
- `LICENSE`: MIT 라이선스

## Install

Codex에서 사용하려면 아래 경로로 설치하면 됩니다.

```bash
git clone https://github.com/ididai/1pro-skill.git ~/.codex/skills/1pro-skill
```

이미 같은 폴더가 있다면 먼저 비교한 뒤 병합하거나 백업 후 교체하세요.

업데이트할 때는:

```bash
cd ~/.codex/skills/1pro-skill
git pull
```

## How To Use

스킬 이름으로 직접 호출하거나, 요청을 더 명확하게 정제하고 싶을 때 자연어로 사용하면 됩니다.

```text
Use $1pro-skill to 이 요청을 실행 가능한 질문으로 정제해줘:
내 앱 좀 더 좋게 만들어줘.
```

```text
Use $1pro-skill to 이 기능 요청을 개발자가 바로 작업할 수 있는 명세로 바꿔줘:
로그인 화면 좀 좋게 고쳐줘.
```

```text
Use $1pro-skill to 비개발자도 이해할 수 있게 쉬운 설명과 추천 기본값까지 붙여줘:
서비스 소개 페이지를 만들고 싶어.
```

## What It Produces

스킬은 상황에 따라 아래 항목을 조합해 응답합니다.

- 목적
- 새 질문
- 작업 명세
- 추가 질문
- 가정
- 초보자 가이드

불필요한 섹션은 생략해서 짧고 실무적으로 답하도록 설계되어 있습니다.

## Example

원문:

```text
로그인 화면 좀 좋게 고쳐줘.
```

결과:

```text
작업 명세:
목표: 사용자가 로그인 상태와 실패 이유를 명확히 이해하고 다시 시도할 수 있게 만든다.
범위: 이메일/비밀번호 입력, 오류 메시지, 로딩 상태, 성공 후 이동, 모바일 반응형.
비범위: 소셜 로그인, 회원가입 정책, 2단계 인증.
입력: 현재 로그인 화면 코드, 기존 인증 API, 디자인 시스템.
출력: 수정된 로그인 UI와 검증 결과.
제약: 기존 인증 API 계약은 변경하지 않는다.
성공 기준: 빈 값, 잘못된 이메일, 틀린 비밀번호, 네트워크 실패, 성공 이동이 모두 처리된다.
검증 방법: 관련 테스트를 실행하거나 수동 체크리스트로 각 상태를 확인한다.
```
