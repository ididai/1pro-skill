# 1pro-skill

`1pro-skill`은 모호한 요청을 실행 가능한 고품질 질문과 작업 명세로 정제하는 Codex 스킬입니다.

이 스킬은 특히 아래 상황에서 유용합니다.

- 요구사항이 두루뭉술해서 바로 작업하기 어려울 때
- 프롬프트를 더 날카롭고 실무적으로 바꾸고 싶을 때
- 누락된 결정사항, 제약조건, 성공 기준을 먼저 드러내고 싶을 때
- 초보자도 이해할 수 있게 쉬운 설명과 추천 기본값이 필요할 때

## Repository Contents

- `SKILL.md`: 스킬 본문
- `agents/openai.yaml`: OpenAI 계열 호출 메타데이터
- `LICENSE`: MIT 라이선스

## Install

Codex에서 사용하려면 아래 경로로 설치하면 됩니다.

```bash
git clone https://github.com/ididai/1pro-skill.git ~/.codex/skills/1pro-skill
```

이미 같은 폴더가 있다면 먼저 비교한 뒤 병합하거나 백업 후 교체하세요.

업데이트할 때는:

```bash
cd ~/.codex/skills/1pro-skill
git pull
```

## How To Use

스킬 이름으로 직접 호출하거나, 요청을 더 명확하게 정제하고 싶을 때 자연어로 사용하면 됩니다.

예시:

```text
Use $1pro-skill to 모호한 요청을 실행 가능한 최고 수준 질문으로 정제해줘.
```

```text
Use $1pro-skill to 이 기능 요청을 개발자가 바로 작업할 수 있는 명세로 바꿔줘.
```

```text
Use $1pro-skill to 비개발자도 이해할 수 있게 쉬운 설명과 추천 기본값까지 붙여줘.
```

## What It Produces

스킬은 보통 아래 형태로 응답을 정리합니다.

- 목적
- 새 질문
- 추가 질문
- 가정
- 초보자 가이드

불필요한 섹션은 생략해서 짧고 실무적으로 답하도록 설계되어 있습니다.
