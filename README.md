# 1pro-skill

`1pro-skill`은 모호한 요청을 실행 가능한 고품질 질문과 작업 명세로 정제하는 Codex 스킬입니다.

## 포함 파일

- `SKILL.md`
- `agents/openai.yaml`

## 설치 방법

Codex에서 사용하려면 이 저장소를 아래 경로로 배치하세요.

```bash
git clone <repo-url> ~/.codex/skills/1pro-skill
```

이미 폴더가 있다면 내용을 비교한 뒤 덮어쓰지 말고 병합 여부를 먼저 결정하세요.

## 사용 방법

Codex에서 스킬 이름으로 호출하거나, 모호한 요청을 더 명확한 작업 지시로 바꾸고 싶을 때 사용하면 됩니다.

예시:

```text
Use $1pro-skill to 모호한 요청을 실행 가능한 최고 수준 질문으로 정제해줘.
```
